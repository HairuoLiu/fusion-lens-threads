Camera Lens and Filter Threads

Free, open-source Fusion 360 add-in that adds standard camera lens and filter thread sizes to the Thread Type dropdown, so you can model step-up rings, filter adapters, lens hoods, and custom caps with real threads.

What it installs

  • 73 sizes from 24 mm to 127 mm (covers 25, 30, 37, 39, 40.5, 43, 46, 49, 52, 55, 58, 62, 67, 72, 77, 82, 86, 95, 105, 112, 127 mm and more).
  • Two pitches: 0.75 mm (most filter sizes) and 1.0 mm (large filters + M39/M42 lens mounts).
  • Both male (external) and female (internal) threads — 292 thread definitions.

How to use

  1. Install this add-in from the Autodesk App Store (or via Scripts & Add-ins).
  2. Run it once. It copies the thread definitions into Fusion's configuration folder.
  3. Restart Fusion 360.
  4. In a model, create a thread (Modify > Thread), open the Thread Type list, and pick Camera Lens and Filter Threads.

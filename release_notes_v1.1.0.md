Latest release — documentation and asset refresh on top of the v1.0.0 thread library.

What changed since v1.0.0:
- Bilingual README (English + 中文) with 7 screenshots end-to-end.
- Added "Which pitch: 0.75 vs 1.0 mm" selection guide.
- Added multi-platform posting kit (reddit-posts/) for X / Reddit / Printables / etc.
- Project re-packaged for the Autodesk App Store as a Fusion 360 add-in (.bundle).

Functional thread library is unchanged:
- LensSizeThreads.xml: 73 sizes (24–127 mm) × 2 pitches (0.75 / 1.0 mm) × 2 genders = 292 threads.
- Installers for Windows (PowerShell) and macOS (bash), plus a Python generator.
- Profile name in Fusion: "Camera Lens and Filter Threads".
